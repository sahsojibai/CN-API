Install the Chattrn package

Have your developer run these in the Laravel app's root, in order.

Install and deploy once, then review mappings here. No manual access-token copying is needed.

Developer with terminal access
composer require chattrn/connector

Set CHATTRN_TOKEN below and CHATTRN_BACKEND_URL to your public Chattrn backend.

php artisan migrate --force && php artisan chattrn:register
Deploy-only hosting (Render Free and similar)

Add the package to your repository. Set the setup token and public backend URL in your host's environment settings.

After migrations, your startup script should run php artisan chattrn:register --no-interaction when CHATTRN_TOKEN is set. Deploy once; the package saves its access token encrypted in your database.

Pairing requires a publicly reachable backend. A store hosted online cannot call a backend at localhost.
